# 做了吗

源码：https://github.com/fuhang122/zuolema
 · 原生安卓版

一个完全离线的私密身体日记。所有数据只保存在本机，不联网、不上传。

## 功能

- 首次启动选择性别：女生 / 男生 / 保密，之后可在设置里切换。
- 日历首页：按月查看记录，今天有玫瑰色圆底，做爱/自慰/其他记录用不同颜色小点标记；点任意一天先看当天列表，可编辑某一次或继续新增。
  - 做爱 / 自慰，单选；一天可以记录多次
  - 做爱方式：无套 / 有套 / 体外 / 自定义；自慰方式：手 / 道具
  - 道具 / 成人视频 / 润滑液 / 情趣内衣 / 其他，可多选，不选就是没有使用
  - 心情：愉悦 / 放松 / 平静 / 低落 / 烦躁
  - 状态：精力充沛 / 放松 / 有点疲惫 / 敏感 / 心不在焉 / 很满足，可多选
  - 快感度 0–5
  - 备注
  - 图片（最多 9 个媒体）、视频、录音（AAC/M4A，最长 10 分钟）
  - 媒体可预览、播放、删除
- 时间轴：累计次数 / 本月次数 / 连续天数统计，按月份分组，可按做爱、自慰、有媒体筛选；点击查看详情、编辑或删除。
- 底栏：日记 / 时间轴 / 设置，固定贴底、无边框、无选中外框。
- 设置：切换性别、深色 / 浅色 / 跟随系统（深色下可开启纯黑背景）、主题色（跟随性别 / 动态取色 / 自定义 HSV）、进入密码、指纹解锁、导出与导入数据、查看本地数据大小、清空全部记录与媒体。
- 进入密码：可选 4 位数字，SHA-256 加盐后只存本机；默认每次切出应用再回来都会重新验证。忘记密码只能清除应用数据。
- 5 分钟免密：开启后输入一次密码，5 分钟内切回应用不再验证；超过 5 分钟或关闭密码后恢复验证。
- 隐藏后台：开启后最近任务和截屏中显示空白，避免别人从后台预览看到日记内容。
- 指纹解锁：设备有已录入指纹时可开启，锁屏会自动弹指纹，仍保留 4 位密码兜底；设置里可随时关闭。
- 性别主题：女生为原来的玫瑰色，男生整套切换为蓝色（背景、卡片、强调色、底栏、系统栏）；保密使用中性灰粉。切换性别会立即换色。
- 纯黑模式：仅在深色模式下可开启；最底层背景和底栏使用 #000000，卡片保留并整体压暗，仍可与底色区分。
- 主题色：默认跟随性别；Android 12 及以上可选系统动态取色；也可用色相 / 饱和度 / 亮度滑杆自定义，自定义会覆盖性别配色。
- 备份与恢复：导出为 zip（全部日记 + 图片 / 视频 / 录音），导入会覆盖当前数据并重建媒体路径。
- 数据只存 `filesDir/entries.json` 和 `filesDir/media/`；应用没有网络权限，不会上传到任何服务器。

## 安装

把 `做了吗.apk` 传到手机，点击安装。首次安装需要允许“安装未知应用”。

- 包名：`com.zuolema.app`
- 版本：1.1.0
- 最低 Android 8.0（API 26），目标 API 34
- 权限：麦克风（录音时申请）、指纹（仅用于本机解锁）；无网络权限

## 构建

需要 Android SDK platform android-23、build-tools、javac、d8、apksigner、zipalign。

```bash
cd zuolema_android
./build_apk.sh
```

脚本会生成并签名 `做了吗.apk`。签名密钥默认读取同目录 `ks.jks`，密码 `dsh123456`；正式使用请换成自己的密钥。

## 关于 arm64

这个应用是纯 Java + Android SDK，不包含 `.so` 原生库，因此没有 ABI 拆分；在 arm64-v8a 手机上由系统以 64 位 ART 运行。已把最低版本提高到 Android 8.0（API 26），不再适配 Android 6/7。

## 密码与备份说明

- 进入密码是应用级门锁，用来挡住随手拿到手机的人，不是文件加密；应用私有目录里的数据仍由 Android 沙箱保护。
- 指纹只通过系统 `FingerprintManager` 做本机认证，应用不会读取或保存指纹图像。
- 导出文件包含私密媒体，请只放到自己信任的位置。
- 导入采用“先解压到临时目录，再整体替换媒体目录”的方式，失败时尽量保留原数据。

## 说明

- 应用没有网络权限，不会连接任何服务器。
- 卸载应用会删除全部记录和媒体。
- 一天可以有多条记录；每次只选做爱或自慰，点日期可继续新增。旧版一天一条的数据会自动迁移。
